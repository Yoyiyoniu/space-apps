Datos

Archivos estáticos del Valle de Mexicali. Empieza por el manifiesto; el resto son rasters y JSON listos para bajar.

Guía rápida

  1. Abre manifest.json. Ahí están el bbox, el tamaño de celda, las fechas, scale, nodata (−32768) y los créditos. No hace falta adivinar unidades.
  2. Los .bin son Int16 little-endian, fila-mayor, fila 0 al norte. terrain.bin es altura × ancho en metros. Cada cube.bin es fechas × altura × ancho. El hundimiento está guardado en mm: multiplica por scale (0.1) para cm.
  3. Caminos, canales, ríos, ejidos y eventos son JSON. Sirven para Excel o GIS; el cubo de radar no cabe bien en una hoja.
  4. Mira source en cada capa. Si dice synthetic, no es una medición NISAR.

Python

import json, numpy as np

m = json.load(open("manifest.json"))
r = m["regions"][0]
h, w = r["height"], r["width"]
dem = np.fromfile("mexicali/terrain.bin", dtype="<i2").reshape(h, w)

capa = next(l for l in r["layers"] if l["id"] == "subsidence")
raw = np.fromfile("mexicali/subsidence/cube.bin", dtype="<i2")
cube = raw.reshape(len(capa["dates"]), h, w)
cm = np.where(cube == capa["nodata"], np.nan, cube * capa["scale"])

Celda (col, fila) con origen en la esquina noroeste. El centro de la celda (i, j) está en (i + 0.5, j + 0.5). Créditos: NISAR NASA/JPL-Caltech e ISRO (ASF DAAC); DEM Copernicus GLO-30.
